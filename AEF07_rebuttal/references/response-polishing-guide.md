# Response Letter 润色规范（Response Polishing Guide）

> 适用于：AEF07_rebuttal 的 `response-polisher` agent。本文件定义 response letter 的称呼、立场、语气与结构要求；通用写作规则见 `shared/writing-principles.md`，两者同时适用。

- 维护规则
  - 新增要求直接在对应类别下追加一条，编号顺延（如 `P3.6`）；新类别则新增 `## 5. ...`
  - 来源标记：`[用户]` = 用户原始要求（保留原话）；`[补充]` = 落地说明或示例，用户可删改
- 范围：全部是描述上的要求，不做实质性更改，只做语言上的润色
  - 不改结论、数字、分析结果、引用、section / table / page 定位、回应立场与修改承诺
  - 如果某句的语气问题不改实质内容就修不了，标记出来交给用户决定，不擅自改

---

## 1. 称呼：Directly address

- `P1.1` [用户] 面对 AE 的时候不要说 "thank the AE/reviewer/R1"，这样会显得很有距离感，直接说 "thank you for..."。
- `P1.2` [用户] 如果对 SE 提到 AE 怎么怎么样，这个时候还是可以用 "AE" 的，不需要把 AE 换成 you，这个替换不要那么机械。
  - [补充] 判断依据是这一段的说话对象：对谁说就对谁用 you；提到第三方（另一位 editor 或 reviewer）时保留其称谓

---

## 2. 立场：谦逊，不贬低他人

- `P2.1` [用户] 绝对不能显得自己很高傲，不要贬低别人。尤其涉及到 differentiate 我们跟他们研究的时候，不能说他们哪里做得不好，而是要说他们提供了很好的基础，我们在这个基础上 build on 并且 extend 他们的东西，要用这样的话术。不要说他们做的不好，我们能他们不能。
  - [补充] 避免："Prior studies fail to account for X, whereas our study addresses this gap."
  - [补充] 改为："Prior studies provide an important foundation for understanding X. We build on this work and extend it by examining Y."
- `P2.2` [用户] 不要去评价对方的 comments（比如去说它是重要的还是怎么样）。
  - [补充] 避免："This is an excellent / important / insightful comment."
  - [补充] 改为客观描述这个 point 和我们研究的关系："Your point about X bears directly on how we interpret Y."
- `P2.3` [用户] 不要摆在一个上位者的角度，要谦逊。
- `P2.4` [用户] 措辞一定要非常注意，不要自傲。

---

## 3. 语气：客观陈述，用事实摆道理

- `P3.1` [用户] 谦卑但自信：承认问题的同时展示我们的 thoughtful response。
- `P3.2` [用户] 避免 defensive 或 over-apologetic。不要自我批评。不要自我批评。不要自我批评。
  - [补充] 避免："We apologize for this oversight." / "Our original analysis was flawed."
  - [补充] 改为陈述现在做了什么："We have clarified X in Section 3.2." / "We now report X in Table 4."
- `P3.3` [用户] 体现 intellectual engagement，而非机械应付。
- `P3.4` [用户] 语气一定不要 defensive，一定要很客观、冷静地去描述他的这个 point 对我们的研究是怎么样的。
- `P3.5` [用户] 如果是能够采取这么一种叙事方式就更好：就是说，我们很重视他说的这些，然后我们仔细地去调研，基于他的观点，我们有一些什么样的改进。哪怕是他错了，我们也不要说"我们的证据驳倒了你"，而是说"我们 test 之后，结果是这样子的，那我们觉得可能那个解释是怎么怎么怎么"，但不要直接说他错了。
  - [补充] 避免："Our evidence refutes this concern." / "The reviewer's argument is incorrect."
  - [补充] 改为："Following your suggestion, we examined X. The results show Y. One possible explanation is Z."
- 总之 [用户]：就是要用客观陈述、用事实摆道理的语气去回应他。

---

## 4. 结构与覆盖

- `P4.1` [用户] 每一段的段首句要是总结性的并加粗。
- `P4.2` [用户] 对于比较长的 response，并列的点可以适当使用 1. 2. 3. 这种标题。
- `P4.3` [用户] 要点对点的回复，确保 comments 里面每个点都被正面回应（如果有没回应到的地方要提醒我）。
  - [补充] 润色时不补写实质内容；没回应到的点只列入 polishing notes 提醒用户
- `P4.4` [用户] 对于一些我们觉得他没有解释清楚的地方，要先说"在我们的理解下，你说的'xxx'意味着 xxx。我们基于这个理解来..."
  - [补充] 英文句式："In our understanding, by 'xxx' you mean xxx. Based on this understanding, we ..."
  - [补充] 只有在现有回复已经按某种理解作答、但没有把这个理解说出来时才补这句；如果这个理解本身是否成立都拿不准，先问用户
