# 审稿回复策略规范

> 适用于：AEF07_rebuttal 的 Response Strategist Agent

---

## 四种回复策略

### [策略: 争取]

**适用场景：** Reviewer 提出了实质性质疑，但可以通过补充分析或论证来说服。

**执行要点：**
- 先肯定 Reviewer 的观察力
- 提供新的分析结果或论证
- 用数据说话，不空谈
- 示例："We appreciate this insightful comment. To address this concern, we conducted additional analysis..."

### [策略: 安抚]

**适用场景：** Reviewer 给了建设性建议，或指出了确实存在的小问题。

**执行要点：**
- 真诚感谢
- 说明已按建议修改
- 指出修改位置（页码/段落）
- 示例："We thank the reviewer for this helpful suggestion. We have revised Section X accordingly..."

### [策略: 坚守]

**适用场景：** Reviewer 的要求不合理（超出论文范围、方法论上不可行、或基于误解）。

**执行要点：**
- 礼貌但坚定
- 解释为什么不做这个修改
- 提供文献支持你的立场
- 绝不攻击 Reviewer
- 示例："We respectfully note that [explanation]. As discussed in [Author, Year], our approach is consistent with..."

### [策略: 让步]

**适用场景：** 修改成本低，且修改后确实能改善论文。

**执行要点：**
- 快速执行
- 明确说明修改内容
- 示例："We agree with the reviewer and have made the following changes..."

---

## Reviewer 立场判断

| 立场 | 信号 |
|------|------|
| 支持 | 整体正面评价，comments 以"建议"为主，用词如 "interesting", "well-written" |
| 中立 | 有实质性问题但态度客观，用词如 "the authors should consider", "it would be helpful" |
| 反对 | 质疑核心贡献或方法论，用词如 "fundamental concern", "not convinced", "major weakness" |

## SE/AE 关系管理

- 开头：感谢 SE/AE 的时间和指导，表达对修改机会的珍视
- 结尾：总结主要修改，表达期待
- 如果 Reviewer 之间有矛盾意见：在给 AE 的信中明确说明你的选择和理由
