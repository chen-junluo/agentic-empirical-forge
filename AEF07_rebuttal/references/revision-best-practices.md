# R&R 修订最佳实践

> 适用于：AEF07_rebuttal 的 Response Strategist Agent

---

## 核心原则

1. **每条 comment 都必须回应** — 即使你不同意，也要说明理由
2. **修改必须可追踪** — 在 Response Letter 中标注修改位置
3. **不要过度修改** — 只改 Reviewer 要求的，不要引入新问题
4. **保持论文一致性** — 修改一处后检查是否影响其他部分

---

## 处理矛盾意见

当两位 Reviewer 给出矛盾建议时：

1. 判断哪位 Reviewer 的意见更有道理
2. 在 Response Letter 中对两位都回应
3. 向 AE 解释你的选择："We note that Reviewer 1 and Reviewer 2 have different perspectives on this issue. After careful consideration, we followed Reviewer X's suggestion because..."
4. 如果无法判断，做两个版本的分析，让结果说话

---

## 时间管理

| 阶段 | 建议时间 |
|------|---------|
| 阅读并消化审稿意见 | 1-2 天（不要立即回复） |
| 制定回复策略 | 1 天 |
| 执行修改 | 2-4 周 |
| 撰写 Response Letter | 3-5 天 |
| 内部审阅 Response Letter | 2-3 天 |

---

## Response Letter 格式规范

- 每条回复前引用 Reviewer 原文（用引用块）
- 新增/修改的文字用蓝色或加粗标注
- 标注修改在论文中的具体位置（Section X, Page Y, Line Z）
- 如果做了新分析，附上结果表格
