# Cover Letter 写作规范

> 适用于：AEF06_connection 的 Cover Letter Writer Agent

---

## 基本要求

- 长度：1 页以内（约 300-400 词）
- 语气：专业、简洁、自信但不傲慢
- 格式：正式商务信函格式

---

## 结构规范

### 1. Opening（2-3 句）

- 明确投稿意图："We are pleased to submit..."
- 论文标题（完整）
- 目标期刊名称

### 2. Paper Summary（1-2 段）

- 研究问题：为什么重要？（1-2 句）
- 方法与数据：简要说明（1-2 句）
- 核心发现：最重要的 1-2 个结果
- 贡献：理论贡献 + 实践启示（各 1 句）

### 3. Journal Fit（3-5 句）

- 为什么选择这个期刊（不要泛泛而谈）
- 引用期刊近期发表的 1-2 篇相关论文
- 如果 nominated editor 有相关研究，可以 subtle 提及

### 4. Reviewer Suggestions

- 列出 2-3 位推荐 reviewer
- 每位附 1 句 justification（基于学术相关性）
- 如有需要回避的 reviewer，简要说明原因

### 5. Closing

- 标准声明：原创性、无重复投稿、所有作者同意
- 通讯作者联系方式

---

## 禁忌

| 禁忌 | 说明 |
|------|------|
| 夸张用词 | "groundbreaking"、"revolutionary"、"first-ever" 等 |
| 过度推销 | 不要把 cover letter 写成广告 |
| 谄媚 editor | 不要过度赞美 editor 的研究 |
| 提及私人关系 | Reviewer suggestion 只基于学术相关性 |
| 过长 | 超过 1 页的 cover letter 会让 editor 反感 |
| 模板感太强 | 避免完全套用模板，要有针对性 |

---

## 期刊特定注意事项

### MIS Quarterly
- 强调理论贡献和 IS 领域相关性
- 提及 IT artifact

### Information Systems Research
- 强调方法论创新或严谨性
- 可以提及跨学科贡献

### Journal of MIS
- 强调实践相关性
- 管理启示要具体

### Management Science
- 强调方法论和模型的严谨性
- 贡献要超越单一领域
