## Status

This project is in early public setup. The repository shape is in place, and the public-facing documentation will expand over time.

Empirical Paper Forge is a working repository for a tool-oriented workflow. It is being organized as a reusable project rather than a one-off workspace.

## What you can expect

- A stable repository structure
- Core files and documentation added in stages
- Public materials that become more complete as the project is cleaned up

## Current focus

Right now, this repository mainly establishes the project frame, naming, and public surface. Detailed documentation will follow after the structure settles.

## What it is not
