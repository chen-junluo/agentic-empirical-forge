# UTD/FT50 期刊常见拒稿原因

> 适用于：06_review 的 Internal Reviewer 和 Review Synthesizer

---

## Desk Reject 常见原因

| 原因 | 说明 | 自查方法 |
|------|------|---------|
| 不在期刊 scope 内 | 研究主题与期刊定位不匹配 | 对照期刊近 3 年发表论文 |
| 贡献不清晰 | Introduction 没有明确说明"我们比已有研究多做了什么" | 检查 contribution 段落是否具体 |
| 方法论不足 | 识别策略不够严谨，缺乏因果推断 | 对照 identification-checklist |
| 写作质量差 | 语法错误多、逻辑跳跃、结构混乱 | 通读检查 |
| 文献过时 | 核心文献超过 5 年，缺少近期研究 | 检查 references 年份分布 |

## Reviewer Reject 常见原因

| 原因 | 说明 | 预防措施 |
|------|------|---------|
| 内生性未处理 | 核心自变量有明显内生性但未用 IV/DID 等处理 | Stage 03 识别策略强化 |
| 稳健性不足 | 只有一种稳健性检验，或检验不够有说服力 | 至少 2 种不同类型的稳健性检验 |
| 机制不清 | 只有相关关系，没有解释"为什么" | 机制检验 + 理论推导 |
| 异质性缺失 | 没有探索效应在不同条件下的差异 | 至少 1 个维度的异质性分析 |
| 替代解释 | 没有排除其他可能的解释 | 安慰剂检验 + 控制变量敏感性 |
| 数据描述不充分 | 描述性统计不完整，样本选择过程不透明 | 完整的 Table 1 + 样本筛选流程 |
| 经济显著性缺失 | 只报告统计显著性，不讨论效应大小 | 系数解读必须包含经济含义 |

## IS 领域特有的拒稿原因

| 原因 | 说明 |
|------|------|
| 理论框架不匹配 | 用了不适合 IS 领域的理论，或理论应用过于表面 |
| IT artifact 缺失 | 研究中没有明确的 IT 组件，看起来像纯经济学/管理学论文 |
| 实践贡献模糊 | 没有说明对 practitioners 的具体启示 |
| 数据来源单一 | 只用一个平台/公司的数据，外部效度存疑 |
