# 审查维度与评分标准

> 适用于：06_review 的 Internal Reviewer Agent

---

## 评分维度

### 1. 方法论严谨性（30%）

| 评分 | 标准 |
|------|------|
| 9-10 | 识别策略无懈可击，稳健性检验全面，内生性处理充分 |
| 7-8 | 识别策略合理，有基本稳健性检验，小问题不影响结论 |
| 5-6 | 识别策略有明显漏洞，稳健性不足，需要补充分析 |
| 3-4 | 因果推断存在严重问题，结论可信度低 |
| 1-2 | 方法论根本性错误，结论不可信 |

### 2. 理论贡献（25%）

| 评分 | 标准 |
|------|------|
| 9-10 | 理论框架新颖且严谨，假设推导逻辑清晰，贡献增量明确 |
| 7-8 | 理论框架合理，假设有据，贡献可辨识 |
| 5-6 | 理论框架常规，假设推导薄弱，贡献不够突出 |
| 3-4 | 理论框架不清晰，假设缺乏逻辑支撑 |
| 1-2 | 无明确理论框架，纯描述性 |

### 3. 数据与结果（25%）

| 评分 | 标准 |
|------|------|
| 9-10 | 数据质量高，描述性统计完整，结果解读含经济显著性 |
| 7-8 | 数据合理，基本统计完整，结果解读准确 |
| 5-6 | 数据有局限但可接受，统计不完整，解读偏表面 |
| 3-4 | 数据质量存疑，统计缺失严重 |
| 1-2 | 数据不可信或不适合回答研究问题 |

### 4. 写作质量（20%）

| 评分 | 标准 |
|------|------|
| 9-10 | 逻辑流畅，表述精准，结构完整，可直接投稿 |
| 7-8 | 整体清晰，少量表述需打磨 |
| 5-6 | 逻辑基本通顺，但有跳跃或冗余 |
| 3-4 | 结构混乱，逻辑不清 |
| 1-2 | 无法理解论文在说什么 |

---

## 严重程度定义

| 级别 | 定义 | 处理要求 |
|------|------|---------|
| `[CRITICAL]` | 影响论文核心结论的有效性，不解决则无法投稿 | 投稿前必须解决 |
| `[MAJOR]` | 显著削弱论文质量，reviewer 大概率会提出 | 强烈建议修改 |
| `[MINOR]` | 小问题，不影响核心结论但影响阅读体验 | 有余力再改 |
